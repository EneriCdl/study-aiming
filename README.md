# Study Aiming - 学习路线可视化

> ✦ 我来带你一步步走！

AI 驱动的个性化学习路线规划工具，帮助学生和自学者系统化地规划学习路径。

## ✨ 特性

- 🌌 **紫色星空主题** - 沉浸式的宇宙视觉体验
- ✦ **粒子动画系统** - 粒子随滚动变换形态（星空 → 土星 → 星图）
- 🤖 **AI 学习规划** - 连接 OpenAI / DeepSeek / 智谱等 AI 服务生成学习路线
- 📄 **文档导入** - 支持 .docx / .txt / .json 格式的学习文档导入
- 📊 **学习仪表盘** - 进度追踪、学习热力图、任务管理
- 🪐 **星球路线图** - 以星球树状图可视化学习阶段
- 💾 **本地存储** - 所有数据保存在浏览器本地，隐私安全

## 🚀 使用

直接访问 GitHub Pages 链接即可使用。

### 配置 AI

1. 点击右上角 ⚙ 设置
2. 选择 AI 服务提供商（OpenAI / DeepSeek / 智谱）
3. 填入 API Key 和模型名称
4. 保存设置

### 创建学习路线

1. 点击「开始规划学习路线」
2. 填入学习内容、当前水平、目标水平等信息
3. AI 自动生成个性化学习路线
4. 按阶段完成任务和测验，解锁下一阶段

### 导入学习文档

1. 点击「导入学习文档」
2. 选择 .docx / .txt / .json 文件
3. 预览并确认导入

## 🛠 技术栈

- 纯 HTML / CSS / JavaScript（零依赖）
- Canvas 2D 粒子动画系统
- LocalStorage 本地数据持久化
- GitHub Pages 部署
